# ⌚ Luxora Watch Website

Luxora Watch is a modern and elegant **watch showcase website** built using **HTML, CSS, and Bootstrap 4**.  
The project focuses on a **luxury UI design**, smooth layout, and full responsiveness across devices.

---

## 🌐 Live Demo  
(https://kishan-savaniya.github.io/Luxora-Watch/)

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap 4  
- Font Awesome  
- Google Fonts  

---

## ✨ Features

- Luxury watch UI design
- Fully responsive layout
- Bootstrap 4 grid system
- Hero section with product highlight
- Product listing / showcase section
- Smooth hover effects
- Clean and minimal design
- Cross-browser compatible
